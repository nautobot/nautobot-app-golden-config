# E3038 Details

## Message emitted:

`E3038: Invalid hier_config match rules in the Partial CLI Config to Match: {details}`

## Description:

hier_config rejected the match rules in the Config to Match field of a Partial CLI compliance rule.

## Troubleshooting:

Check the rule block and field named in the error, for example a misspelled keyword such as `startwith`, or a rule block without `match_rules`.

## Recommendation:

Use only the `match_rules` key in each rule block, with the keywords `equals`, `startswith`, `endswith`, `contains` or `re_search`.
