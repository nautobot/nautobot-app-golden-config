# E3037 Details

## Message emitted:

`E3037: Invalid structure in the Partial CLI Config to Match, {details}.`

## Description:

The Config to Match field of a Partial CLI compliance rule is valid YAML, but not a non-empty list of rule blocks.

## Troubleshooting:

Check that the Config to Match field is a YAML list, and that each entry of the list is a mapping with a `match_rules` key.

## Recommendation:

Start each rule block with `- match_rules:`, followed by its list of match rules. See the Partial Configuration Compliance documentation for examples.
