# E3035 Details

## Message emitted:

`E3035: Cannot generate config plans, the Golden Config Setting of these devices does not select a Config Plan Approval Workflow: {devices}.`

## Description:

The Generate Config Plans job did not create any Config Plan because a device in scope has no Config Plan Approval Workflow selected by its Golden Config Setting, or no Golden Config Setting applies to it.

## Troubleshooting:

Edit the Golden Config Setting that applies to the devices, which is the matching setting with the highest weight, and select a Config Plan Approval Workflow.

## Recommendation:

Select a Config Plan Approval Workflow on the Golden Config Setting, then generate the config plans again.
