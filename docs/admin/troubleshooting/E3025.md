# E3025 Details

## Message emitted:

`E3025: Cannot deploy configuration(s). One or more config plans are not approved: {device} ({approval state}), ....`

## Description:

The **Deploy Config Plans** job does not deploy any configuration when a config plan in the batch is not approved, and the job fails. A plan is approved only when its Approval Workflow is `Approved`. A plan without an Approval Workflow cannot be deployed.

## Troubleshooting:

The message lists the devices of the plans that are not approved, up to ten, with the state of the approval workflow, or `No workflow`. For a `Pending` workflow, approvers still need to approve it from the Approver Dashboard. For a `Denied` or `Canceled` workflow, or a plan with no workflow, the plan must be deleted and generated again.

## Recommendation:

Remove the unapproved plans from the deployment, or get them approved, and run the job again. See [Approving Config Plans](../../user/app_feature_config_plans.md#approving-config-plans).
