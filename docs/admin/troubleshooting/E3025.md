# E3025 Details

## Message emitted:

`E3025: Cannot deploy configuration(s). One or more config plans are not approved: {device} ({approval state or status}), ....`

## Description:

The **Deploy Config Plans** job does not deploy any configuration when a config plan in the batch is not approved, and the job fails. A plan with an Approval Workflow is approved only when the workflow is `Approved`. A plan without one is approved unless its status is still `Not Approved` (the `default_deploy_status`) or `Pending Approval`.

## Troubleshooting:

The message lists the devices of the plans that are not approved, up to ten, with the approval state of the workflow or the status of the plan. For a `Pending` workflow, approvers still need to approve it from the Approver Dashboard. For a `Denied` or `Canceled` workflow, the plan can be resubmitted for approval, or generated again.

## Recommendation:

Remove the unapproved plans from the deployment, or get them approved, and run the job again. See [Approving Config Plans](../../user/app_feature_config_plans.md#approving-config-plans).
