# E3039 Details

## Message emitted:

`E3039: Invalid remediation options in the Remediation Settings of platform `{platform}`: {error}`

## Description:

Partial CLI compliance parses configurations with the remediation options of the platform's Remediation Settings, and hier_config cannot load them.

## Troubleshooting:

Check the Remediation Options of the Remediation Settings of the device's Platform.

## Recommendation:

Fix the Remediation Options so hier_config can load them, or clear them.
