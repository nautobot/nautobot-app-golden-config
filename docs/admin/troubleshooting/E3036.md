# E3036 Details

## Message emitted:

`E3036: Invalid YAML in the Partial CLI Config to Match: {error}`

## Description:

The Config to Match field of a Partial CLI compliance rule cannot be parsed as YAML.

## Troubleshooting:

Check the Config to Match field of the Partial CLI compliance rule for YAML syntax errors, such as wrong indentation or unclosed brackets.

## Recommendation:

Fix the YAML syntax of the Config to Match field. See the Partial Configuration Compliance documentation for examples.
