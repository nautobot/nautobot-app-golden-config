# E3035 Details

## Message emitted:

`E3035: There is currently no hier_config support for platform network_driver `{network_driver}`, required by Partial CLI compliance rules.`

## Description:

Partial CLI compliance rules are matched with hier_config, but hier_config has no support for the platform's network driver.

## Troubleshooting:

Check the Network driver of the device's Platform, and the `hier_config` entry of its Network driver mappings.

## Recommendation:

Set the Platform's Network driver to one supported by hier_config, for example `cisco_ios`, `cisco_nxos` or `arista_eos`, or map the network driver to a supported hier_config platform with the `NETWORK_DRIVERS` setting.
