# E3035 Details

## Message emitted:

`E3035: Cannot resubmit `{config_plan}` for approval: {reason}.`

## Description:

A Config Plan can only be resubmitted when its approval workflow was denied or canceled and its deployment has not started.

## Troubleshooting:

Check the approval state and status of the Config Plan.

## Recommendation:

Generate a new Config Plan if the approval workflow definition was deleted or the deployment has already started.
