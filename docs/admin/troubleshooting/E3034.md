# E3034 Details

## Message emitted:

`E3034: Reference to tag {tag_reference} is not available for {model}.`

## Description:

Syncing Golden Config properties using the Datasource feature, but a referenced tag does not exist or is not associated with the model&#39;s content type.

## Troubleshooting:

The tag referenced in the YAML file cannot be found for the relevant object type. Confirm the tag exists AND that its `content_types` includes the model being synced (the directory name maps to the model, e.g. compliance_rules -&gt; ComplianceRule).

## Recommendation:

Create the tag in Nautobot and associate it with the {model} content type before syncing, or correct the tag reference in the YAML file.
