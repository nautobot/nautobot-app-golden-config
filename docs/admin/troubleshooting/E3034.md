# E3034 Details

## Message emitted:

`E3034: Cannot start approval workflow `{definition}` for the config plan on `{device}`, the definition has no stages.`

## Description:

A Config Plan was generated for a device whose Golden Config Setting names an Approval Workflow Definition that cannot be started, so the Config Plan was not created.

## Troubleshooting:

Open the Approval Workflow Definition referenced by the Golden Config Setting and check that it has at least one stage.

## Recommendation:

Add an approval stage to the Approval Workflow Definition, or remove it from the Golden Config Setting.
